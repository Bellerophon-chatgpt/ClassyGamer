# The Classy Gamer — site

Astro + Tailwind, statisch, zero-JS. Content als MDX in `src/content/reviews/`.

## Lokaal draaien

```sh
cd site
npm install
npm run dev     # http://localhost:4321/reviews/the-witcher-3/
npm run build   # statische output in dist/
```
